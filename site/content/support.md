# 開発支援・スポンサー
Asteraの開発、検証、Security、運用、専門Knowledge、法人Use Caseを前へ進めるため、支援、Sponsor、CAMPFIRE、技術協力、事業提携を目的と契約の性質ごとに分けて案内します。

## 個人の開発支援
Asteraの開発と公開を応援する任意支援です。支援によってAstera Appの利用権、Credit、株式、持分、配当、利益分配、利息、元本返済は付与されません。
支援金の用途例：
- Server・配信
- API利用
- Security
- Test・検証
- 法務確認
- Accessibility
- 専門Knowledge Base

[開発支援の詳細](/support/development/)

## Sponsor・協賛
公式HPの専用区画へ、承認された名称、Logo、紹介文、Linkを掲載する協賛契約です。Astera App内へ広告やSponsor表示は行いません。
決済完了だけで自動公開せず、本人・法人確認、契約、Logo利用許可、掲載内容、掲載期間を確認してから公開します。

[Sponsor・協賛の詳細](/support/sponsor/)

## CAMPFIRE
CAMPFIREでの支援は、CAMPFIRE上のProject、募集期間、Return、活動報告に基づく別の支援契約です。Asteraの月額利用、追加購入、直接支援、Sponsor契約とは分けて扱います。

[CAMPFIRE Projectを見る](https://camp-fire.jp/projects/968933/view)

## 技術・専門開発協力
Code、Security、法務、UX、Accessibility、専門Knowledge、Test、法人PoC等の協力を受け付けます。作業前に、Scope、成果物、報酬、権利、公開、NDA、Access範囲、検証方法を合意します。

[開発協力について問い合わせる](/contact/?category=development)

## 大型支援・事業提携
大型支援、共同開発、販売・導入協力、法人PoC、事業提携は、本人・法人確認、NDA、法務・税務確認、条件協議、個別契約を経て進めます。一般支援Checkoutへ投資契約を混在させません。

[法人・事業提携について相談する](/contact/?category=corporate)

## 支援者・Sponsorの掲載
掲載を希望し、公開内容へ明示同意し、Astera側の公開承認を受けた方だけを専用区画へ掲載します。支援金額、Email、決済情報、内部IDは公開しません。

[支援者・Sponsorを見る](/supporters/)

## 独立性
支援、Sponsor、協業によって、Asteraが生成する判断材料、Evidence、比較、推奨を変更しません。利用者Data、Secret、未公開AssetへのAccessも付与しません。
