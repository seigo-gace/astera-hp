# Asteraとは？
## 結論
Astera v8は、もう一つのチャットAIや生成AIではありません。
質問、資料、事業計画、設計、研究内容、Source Code、Log、他のAIが生成した回答などを受け取り、複数の視点と独立した処理工程から検討し、**人間または主役AIが判断に使用できる材料へ変換する認知実行基盤**です。
正式名称は、**Astera v8 — Multi-Perspective Cognition Runtime**です。
> 最終回答を生成するAIを増やすのではなく、最終回答を作る前に必要な確認・反対・比較工程を、再利用できる形へ整える。
これがAsteraの中核です。

## Asteraは何を受け取れるか
- 人間の質問、相談、判断、計画
- AIが生成した回答、調査結果、Code
- 事業計画、料金案、企画書、営業資料
- Repository、Source Code、Log、Test結果、設計資料
- 論文、仮説、調査資料、引用
- 会議記録、社内規定、Project計画
- 文書、表、URL、利用者が所有するData

単なる短い質問だけではなく、**「この内容を採用してよいか」「何が足りないか」「どの案を選ぶべきか」を判断したい対象**を入力できます。

## Asteraが返すもの
Asteraは結果を、一つの長文へ押し込まず、次の成果物へ分けます。
1. Cognitive Map
2. 8項目の判断材料セット
3. Compact Output
4. 主役AIへ渡す再指示Prompt
5. LLMを接続している場合の任意の最終回答

中心となるのは、次の8項目です。
1. 本当の目的
2. 前提不足
3. 事実確認
4. 危機察知
5. 反対視点
6. 比較案
7. 推奨判断
8. 主役AIへの再指示

AsteraはChatGPT、Claude、Gemini、自作AI、自社AIの競合ではありません。今使っているAIを主役のまま残し、そのAIへ渡す材料を外側から強化します。

## 「外付けAI強化外装」とは
Asteraの接続形態を、**Astera Docking Exoshell**と表現します。
これは、主役AIの外側へ接続する判断品質の外付け強化外装という意味です。中のAIを入れ替えるのではなく、外側から次の装備を加えます。
- 目的確認
- 前提確認
- Factと未確認情報の分離
- Risk検出
- 反対意見
- 複数案比較
- Evidence
- 再指示

APIによる自動接続だけを意味しません。**人間がAsteraの結果をコピーし、主役AIへ貼り付ける手動接続も同じ仕組みに含まれます。**

## 特定AIへ依存しない
Asteraは、特定のAI会社や一つのAPIへ閉じません。
- ChatGPTを使い続けられる
- ClaudeやGeminiへ同じ判断材料を渡せる
- 自作AI、自社AIへ組み込める
- API接続をしなくても利用できる
- AIを接続せず、人間の判断資料としても使える

難しい連携をしなくても、問いやAI回答をコピーして貼るだけで、Asteraの認知処理を利用できます。

## 人間との関係
Asteraは、人間の判断を奪いません。
- 迷いを消すのではなく、迷いの原因を分解する
- 答えを押しつけるのではなく、比較できる状態を作る
- 不明なことを勝手に断定せず、未確認として残す
- 推奨候補だけでなく、採用条件と見送り条件を示す
- 最終決定権を利用者または権限を持つ組織へ残す

星図が道そのものではないように、Asteraも最終決定そのものではありません。
> **現在地、見落とし、危険、進める道を見える状態へ変える。**
それが「問いを星図に変える。」の意味です。

## Asteraが目指す価値
Asteraは、回答を長くするためのServiceではありません。
- AIの流暢さと正しさを分ける
- 見落としを発見しやすくする
- 分野に応じて確認方法を切り替える
- 複合分野の衝突を発見する
- 一案への固定を防ぐ
- AI回答を検証対象へ変える
- 判断工程を共通化する
- 人間の判断権を残す

## 向いている問い
- 複数案から選ぶ必要がある
- 判断を誤ると手戻りや損失が大きい
- Evidenceや一次情報が必要
- 反対意見やRiskを含めて検討したい
- AIの回答が自然だが、本当に正しいか不安
- 調査、企画、比較、レビュー、改善を深めたい
- 主役AIへ渡す指示を作り直したい

## 向いていない問い
単純計算、短い雑談、答えが一つに確定している軽い確認など、前提・Risk・比較を広げる必要がない場面では、通常のAIや検索だけで十分な場合があります。

## 重要事項
Asteraの出力は判断材料です。Asteraが示す推奨候補は、医師、弁護士、金融専門家、行政機関、組織の決裁者等による最終判断を代行するものではありません。重要な判断では、Evidence、対象条件、一次情報、自身への適合性を確認してください。
