Webhook Gateway

決済や外部Serviceなどから届くEventを受け取り、必要なSystemへ安全に渡すEvent連携基盤です。

何をするSystemか

Webhook Gatewayは、決済や外部Serviceなどから届くEventを受け取り、必要なSystemへ安全に渡すための独立したEvent連携基盤です。Astera本体へ外部連携処理を直接詰め込みません。

Webhookとは

外部Serviceで何かが起きたとき、その出来事を別Systemへ知らせる仕組みです。決済状態の変更、外部処理の完了、GitHub Event、業務Systemからの通知などを次の処理へつなげます。

なぜGatewayへ分けるのか

  • 正しい送信元から届いたものか確認する
  • 同じEventを重複処理しにくくする
  • 配送できなかったEventを追跡しやすくする
  • 必要に応じて再処理できる状態を保つ
外部Service→Webhook Gateway→Astera App / Astera v8 / 関連System

Securityと公開境界

公開Pageでは、送信元確認、重複防止、追跡性などの考え方まで説明します。署名検証の内部方式、非公開Endpoint、Retry条件、内部Queue、監視値などは公開しません。
