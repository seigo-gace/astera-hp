01

公開前Status

Astera Appはクラウドファンディング終了まで一般公開しません。

このページは、公開前にAppの機能、操作、Option、Planとの関係を理解するための公式説明ページとします。公開前はLogin、Account登録、App起動、Checkoutを表示しません。

  • App一般公開：クラウドファンディング終了まで停止
  • Login・Account登録：非表示
  • 実App起動：非表示
  • Checkout：非表示
  • 表示するもの：機能、操作Flow、Option、Plan差、公開予定範囲
  • CTA：料金プラン、CAMPFIRE、Q&A

03

主な機能

1｜入力・Composer

  • 文章を入力する。
  • Enterは改行、送信は明示操作とする。
  • Fileを添付する。
  • ＋から目的とOptionを選ぶ。
  • 選択内容はComposer上部のChipで確認・解除できる。

2｜目的選択

レビュー、比較、検証、改善、調査、計画、検討等、何をしたいかを選択し、Asteraへ処理目的を伝える。

3｜実行前確認

  • 入力内容。
  • 選択した目的。
  • 選択したOption。
  • 添付File。
  • 消費予定Credit。
  • Private Mode等のData取扱い。

確認後に利用者が明示して実行する。

4｜Asteraの結果

Asteraは最終回答だけを置くのではなく、次の8項目を判断材料として整理する。

  1. 目的
  2. 前提不足
  3. 事実・根拠
  4. Risk・危険
  5. 反対視点
  6. 比較案
  7. 推奨判断
  8. 主役AIへの再指示

5｜履歴・Project

  • 実行履歴を検索・Filterする。
  • 単階層Projectへ整理する。
  • 回答を編集、Copy、削除、Downloadする。
  • Revisionと再実行を管理する。

6｜共有

  • Public Share。
  • 指定Account向けPrivate Share。
  • 公開範囲、Password、Download可否を設定する。
  • Private Modeの内容を自動共有しない。

7｜Settings

  • Option表示設定。
  • 表示・言語。
  • 通知・Credit警告。
  • Account・Security。
  • Plan・Subscription。
  • Credit・購入。
  • Data・Privacy。
  • 開発者モード。
04

追加実行Option

追加実行Optionは、Composerの＋から利用者が選んだ場合だけ実行・Credit見積りへ含める。

Option利用者向け説明選択項目
高精度翻訳原文の意味と構造を保持し、指定言語へ翻訳する翻訳先言語、任意の翻訳元言語・用語集
エージェントモードAsteraの判断材料とAI利用を組み合わせ、処理深度を選択するエージェント低／中／高
書類作成公式Templateまたは作成済み個別Templateを使い、指定構造の書類を作るTemplate、構成、出力条件
外部Storage転送処理結果を利用者が選択した外部Storageへ転送する接続先、保存先、転送条件
05

Option設定に含む独立機能

次は追加実行Optionと混同しません。

  • Private Mode：Basic以上で利用するData取扱い方式。本文をAstera履歴、Astera Storage、TGserver、Backupへ保存しない。
  • 暗号化・鍵管理：AppのKey・Secret・大容量Dataを保護する基盤。
  • Astera Storage：通常Mode側で利用するAstera提供Storage。容量別に月次Creditを減算する。
  • 開発者モード・API：Pro以上のAPI Catalog、Key、Explorer、Usage、OpenAPI等。
06

Private Modeと保存

  • Private Modeは追加実行Optionではない。
  • Private Mode自体の追加Creditはない。
  • Private Modeでは結果を端末Downloadまたは外部Storage転送で残す。
  • Astera Storageへ保存する場合はPrivate ModeをOFFにした通常Modeとして扱う。
07

File

  • 複数File添付に対応する。
  • Planごとに1 File容量、1回の件数、合計容量が異なる。
  • 対応上限は料金プランで比較する。
  • 添付失敗、容量超過、非対応形式を実行前に表示する。
08

開発者モード

Pro以上を対象に、次を一つの画面群で管理する。

  • API Catalog。
  • API Key。
  • Request Explorer。
  • Usage。
  • OpenAPI。
  • Versionと利用可能Status。

日本語解析MCP本体と、Appの開発者向けAPIを混同しない。

09

対応端末・操作

  • Smartphone、Tablet、Desktop Webへ対応する。
  • 縦画面・横画面で責務を失わない。
  • 余計な横Scrollを発生させない。
  • Keyboard、Touch、Screen Readerへ対応する。
  • 投稿内容と結果はAccordionで整理する。
10

Customer AI

  • 全画面共通の案内入口。
  • Appの操作、Plan、Credit、Option、Errorを案内する。
  • 利用者の処理結果を勝手に保存・共有しない。
11

Planとの関係

  • Free／Basic／Pro／Business／Enterpriseを用意する。
  • Planごとの月額、月次Credit、File、Storage、Option、API差は料金プランで表示する。
  • App説明Pageでは契約ButtonやPlan選択を置かない。
12

公開前CTA・公開開始後の導線

公開前CTA

  1. 料金プラン・Creditを見る
  2. CAMPFIREで支援・最新情報を見る
  3. Q&Aを見る

公開開始後の導線

  • クラウドファンディング終了後、公開準備と検証が完了した時点で実App起動CTAを有効化する。
  • 公開前は実App URL、Login、登録、Checkoutへ誘導しない。
13

UI・見せ方

  • Appの外装をそのまま巨大Screenshotで並べず、入力→Option→8項目結果→履歴・共有のFlowで説明する。
  • 機能はIcon、短い見出し、1〜2文の説明で整理する。
  • Optionは4項目を同じ幅で比較する。
  • Private Mode、暗号化、Storage、APIを追加実行Optionの列へ混ぜない。
  • Mobileは1列で読み進められる。
14

合格条件

  • TOP第10項目から/app/へ到達する。
  • 実App公開前にLogin、登録、Checkout、App起動を出さない。
  • 最新4追加実行Optionを表示する。
  • Private Mode、暗号化、Astera Storage、APIをOptionと混同しない。
  • 8項目結果、履歴、Project、共有、Settingsを欠落させない。
  • 料金Pageへ到達できる。
  • Desktop／Tablet／Mobileで内容を読める。
